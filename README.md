# schmishape

A parametric CAD app that runs in the browser, built on the [CoreShape](../core_shape) kernel. The
kernel runs locally as WebAssembly, so modelling needs no server and works offline.

```sh
pnpm install
pnpm dev          # builds the engine, then serves http://localhost:5183
pnpm build        # type-checks and builds a static site into dist/
pnpm smoke <url> <folder>   # drives the app in headless Chrome, saving screenshots to the folder
pnpm smoke:regions <url> <folder>   # the same, for extruding a sketch's regions
pnpm smoke:tabs <url> <folder>      # the same, for tabs and folders
node scripts/smoke-dialog.mjs <url> <folder>     # the same, for the feature dialogs
node scripts/smoke-rollback.mjs <url> <folder>   # the same, for going back to an earlier feature
node scripts/smoke-assembly.mjs <url> <folder>   # the same, for assemblies and mates
node scripts/smoke-assembly-more.mjs <url> <folder>   # tangent and width mates, patterns, replicate, exploded views, positions
node scripts/smoke-drawing.mjs <url> <folder>    # the same, for drawing tabs
node scripts/test-assembly-solver.mjs            # the mate solver alone, with exact answers
```

It needs Rust with the `wasm32-unknown-unknown` target, Node and pnpm, and `core_shape` next to this folder.

The engine is built from the kernel's commit named in `engine/kernel-rev`, now `9bc7f68` on the kernel's `next` branch,
which has drawings, the rest of the assemblies and the loft options and isn't on its master yet. The build exports that
commit with `git archive` into `engine/.kernel/`, which only reads the kernel's repository, and builds against the copy.
`KERNEL_REV=<commit> pnpm engine` builds from another. Once the kernel's master has that work, delete `engine/kernel-rev`
to build from the checkout again. Until then a build from the checkout fails, as `engine/Cargo.toml` names the drawing
crate that master doesn't have yet.

Open it in a real browser. An editor's built-in preview may have no WebGL: VS Code's does not on a snap install with NVIDIA, which reports `webgl: disabled_off` under `code --status`. The app says so in the viewport.

## What it does

- **Sketches:** lines, rectangles, circles, arcs and points on a plane or a flat face. Snapping infers
  constraints as you draw. Dragging, dimensions and every constraint go through the kernel's solver, and
  the toolbar shows how much freedom is left.
- **Sketch tools:** line, corner and center rectangle, center and 3-point circle, 3-point, center and tangent arc, straight slot (O), inscribed polygon (Shift P, + and − change its sides), spline, point, text (Shift W), trim, extend (Shift X), corner rounding, offset (Shift O), mirror (Shift M), linear and circular patterns, and dotted construction lines (Q). A slot keeps its round ends tangent and equal, a polygon stays regular, and a mirror's copies are tied to the originals by symmetric constraints, as in Onshape. An offset takes every curve joined end to end to the one clicked, or what's selected. The pointer sets how far and to which side, corners meet where the copies cross, and smooth turns stay smooth. A pattern takes the selected curves and a count, with a step across and up or an angle and a point to turn about. Each shows one dimension, the offset or the step, and typing into it moves every copy while the originals stay put. The kernel has no offset or pattern constraint, so the app builds them from distances, angles and hidden construction lines, kept with the document by sketch. Text is set in the kernel's built-in font (220 characters of Noto Sans): click where it starts, type it (Shift Enter for a new line, Enter to set it), and double-click it to change the words. Ctrl C and Ctrl V copy texts with the rest of a selection, pasted under the pointer. Its height is a dimension and it stays upright, both ordinary constraints on its two points, and its letters make regions like any other curves, so it extrudes raised or cut in. Lines snap to right angles, tangents, midpoints and alignments, with a small icon for each. M or the magnet turns that off, and holding Shift ignores it for a moment.
- **Sketch regions, as in Onshape:** every closed area a sketch's curves make is shaded and can be extruded by itself, including the pieces where shapes cross, and a circle inside a rectangle gives you the ring and the disc separately. Click regions in the view, or a sketch in the list for all of it. All of a sketch keeps a loop in a loop as a hole, unlike Onshape, which fills it unless you drop the inner region. A sketch stays on show until every region has been used, so one sketch can make several extrudes at different lengths. While you pick regions, an added extrude's preview is see-through over the model before it, as in Onshape, so every shape stays in sight and can be clicked from any angle. A cut stays solid, because the hole is what you need to see, and Final shows the finished model.
- **Features:** extrude, revolve, sweep, loft, helix, fillet (with a variable radius, and a radius halfway, so a whole rim can go 2 to 4 and back), chamfer, shell, draft, rib, hole, offset, thicken, delete face, copy faces, mirror, linear and circular patterns, transform (move, copy, rotate, scale or stretch parts), boolean, split, and delete part, each with a live preview. Refusals appear in the
  dialog with the kernel's reason. A file or an AI can still add box, cylinder, cone, sphere and torus features,
  and they can be edited, but there are no tools for them.
- **Extrude, as in Onshape:** it takes a part's flat faces as well as sketch regions, in the same box: click the top of a block to build up from it, or flip it with Remove to cut down into it. Selecting a flat face first, or right-clicking one, starts an extrude of it. Ends are Blind, Up to next, Up to face, Up to part, Up to vertex and Through all, with the flip beside them. One extrude can take regions from several sketches. Choosing an end that needs a pick hands the clicks to its box, and clicking any box takes them back: only the box with the lit edge takes clicks, as in Onshape.
- **Revolve, as in Onshape:** it takes sketch regions, from one sketch or several in the same plane, and turns them about any line of the sketch, construction or not, or the sketch's own axes. With its regions already picked, the axis box takes the clicks next. The revolve follows that line when the sketch changes.
- **Merge scope, as in Onshape:** Add, Remove and Intersect act on every part they reach until Merge with all (Remove from all, Intersect with all) is turned off, and then only on the parts picked in the view. Until one is picked, the preview shows the shape as a part of its own. Extrude, revolve, sweep, loft, helix and thicken all have it.
- **Mirror and patterns, as in Onshape:** Part mirror or pattern copies the parts picked in the view, or every part with none picked. Feature mirror or pattern copies features, clicked in the list or by a face they made in the view. Fillet and chamfer have Tangent propagation, on unless you turn it off.
- **Planes, as in Onshape:** the Plane tool, beside Sketch, makes all eight of Onshape's types: offset, plane point, line angle, point normal, three point, mid plane, curve point and tangent, each with Flip normal. Each box takes what Onshape's does, clicked in the view or the list: Top, Front, Right, other planes and flat faces; corners, sketch points and the origin; edges, sketch lines and the axes of round things. A plane is worked out again at every rebuild, so it follows what it's made from, and a sketch on it follows the plane. Planes show in the list with an eye, which hides them with the document, and P shows or hides every plane. Mirror, trim and draft take any plane, an extrude can end up to one, and a pattern can go along or around a picked line.
- **Sheet metal, as in Onshape:** Sheet metal model makes a part of one thickness from a sketch: a closed outline is a flat plate, and a chain of lines makes walls with a bend at each corner, with Thickness (and which side it grows to), Depth, Bend radius and K factor. The model also sets Flange corners, Open or Closed, and a Minimal gap for the folds after it. Flange adds a bend and a wall along the edges picked, with Outer, Inner or Bend alignment, length, angle, flip, its own bend radius if you want one, and its corners as the model says, open or closed. Hem folds an edge back over its wall: Straight with a gap, Rounded, Teardrop or Rolled, with alignment, length, angle and flip. Tab adds regions sketched on a wall, as thick as the sheet. Bend folds the part along a line sketched across a wall, centred on the line or starting at it, either side moving, and the flat pattern stays as it was. Flat pattern opens the part laid flat beside the model: its outline and holes, bend lines dashed (up and down drawn differently, each with a note), its size, area, thickness and K factor, and a table of the bends. Point at a row to light its line. Scroll zooms the flat view, dragging pans and a double-click fits it. It follows the rollback bar and a dialog's preview, and exports as a DXF with the outline, holes, bends up, bends down and bend notes on separate layers. Sheet metal parts have their own icon, and right-clicking one offers its flat pattern.
- **Sweep, as in Onshape:** the path is picked in the view: click a sketch's curve for all of that sketch's curves, end to end, or click a part's edges. Older sweeps made of straight runs and bends keep that form.
- **Manipulators, as in Onshape:** a blind extrude shows an arrow from where it starts to where it ends, with the depth beside it. Drag its head to set the depth, in steps that suit the zoom. An offset plane's distance and Thicken's thickness have one too.
- **Loft profiles, as in Onshape:** click regions in the view, or sketches in the list, in the order the loft passes through them. One region of a sketch with several outlines can be a profile. A loft can also start or end at a point (a sketch point, a part's corner or the origin), as a cone does, with Round to dome over it; close into a ring through three profiles or more; follow guides, sketches of open curves ticked in a list; and leave its first or last profile Normal to it, each end with a pull. The kernel can't yet do guides with set ends, or a closed loft with guides, and says so.
- **Surfaces:** Solid or Surface on extrude, revolve, sweep, loft and helix, and Fill (a flat surface in each closed area of a sketch), Copy faces, Sew (closed up, surfaces become a solid) and Trim surface (by a part, a plane or a sketch). The Parts list shows surfaces under their own heading.
- **Sidebar, as in Onshape:** Default geometry (origin and planes, each with a show or hide eye), Features with a filter, and Parts and Surfaces, one row per body as the kernel counts them. Right-click a part to rename it (or double-click it), edit its appearance, hide it or delete it. Names and colors are kept in the document's `app` data, by the kernel's name for the part, so they save with the file and an AI can read them. Right-click a feature to edit, rename, turn off, delete or roll to it. Drag a feature up or down the list to move it in the history, as in Onshape: a line shows where it will go, and a move that would put something before what it uses is refused, by name. Sketches have an eye too: a sketch a feature has used is hidden until you show it, and any other can be hidden. New features go in at the rollback bar.
- **Going back, as in Onshape:** double-click a feature or a sketch to edit it, and the model shows how it stood at that step, with everything after it gone and the camera left alone. A single click only selects. Finishing or cancelling puts the rollback bar back where it was. Final, in the dialog, shows the finished model while you edit. Right-click a row for Roll to here, or the bar for Roll to end. Drag the bar, or click it and use ↑ and ↓ to step through.
- **Assemblies:** insert parts from any Part Studio (`I`), then drag them or use the triad. Click a part for the triad, and drag a part to move it freely. Mates (`M`, or the toolbar) offer connectors on hover, as in Onshape: flat faces at the centroid, vertices, edge midpoints and arc centers; round faces along the axis; edges at their middle and ends. Hold Shift to stay on a face or edge. The first part picked moves to the second. Fastened, Revolute, Slider, Planar, Cylindrical, Pin slot, Ball, Parallel, Tangent and Width are in, with flip and reorient, and the toolbar shows the freedoms left. A mate that can't hold says which one it conflicts with. Assemblies autosave with their tab and have their own undo, and instances follow their Part Studio when you come back.
- **Tangent and Width mates, as the kernel's:** Tangent keeps two faces touching, from the faces its connectors are on: a cylinder lies level on a plane (even one standing straight up tips over), two cylinders keep parallel axes their radii apart, balls rest on planes and each other, and flip puts it on the other side or one inside the other. Width takes two parallel faces each side, such as a tab's sides and a slot's, and keeps the tab's middle on the slot's middle plane. Click one face, then the face across from it; the same face twice uses just that face.
- **Patterns, Replicate, Exploded views and Named positions:** a linear or circular pattern of parts, along X, Y, Z or a picked face or edge, which then follows its part; Replicate, copies of parts at every face of another part like the one picked, such as a screw in every hole of the same size the same way. Copies are placed after the mates are solved, from where their parts end up, so they follow them, and they can't be mated. An exploded view is steps that each move the parts selected by a shift, shown by clicking it in the list, with a slider for how far; only the view moves. Save named position keeps where every part is, and clicking it takes them back, as far as the mates let them.
- **Drawings, as in Onshape:** Create Drawing, from + by the tabs or the File menu, makes an engineering drawing of a Part Studio, one of its parts, or an assembly (with its pattern copies), laid out by the kernel each time it's shown, so it follows the model. It starts with front, top, right and isometric views on A3 in first-angle projection at the largest standard scale that fits, with overall sizes and hole diameters. Add views and sections (parallel to Front, Top or Right, at a distance, lettered A, B, …), and dimensions between sketch points or typed places, measured horizontal, vertical or aligned, or a circle's diameter or radius, with text around the value. A dimension the kernel can't draw is refused with its reason. The sheet (A4 to A0, ANSI A to E), projection, scale, automatic dimensions, which views show hidden lines and the ISO 7200 title block are in the side panel. Export writes PDF, SVG, DXF or PNG. Wheel zooms the sheet, dragging moves it, and a double-click fits it. Drawings have their own undo, and are kept with versions and the whole-document file.
- **Feature dialogs, as in Onshape:** drag the header to move one and its edges to resize it, and it stays where you put it. Double-click the header to put it back. Solid and Surface are the tabs along the top, New, Add, Remove and Intersect sit under them, and what you've picked is listed in a tinted box with a × on each row. Extrude has End type with a flip button, Depth, Symmetric, Starting offset and Second end position, all taking expressions. The slider by Final sets how solid its preview is, from the model before it to the model after it.
- **Hole, as in Onshape:** a hole at the sketch points you click: points, circle centres or line ends, all from one sketch. It opens with every point of the last sketch picked, and clicking one drops it. A hole that takes every point of its sketch also drills points added to it later. Each hole is Simple, Counterbore or Countersink, in a metric size from M1.6 to M36 with a Close, Normal or Loose fit, or tapped, or a Custom size typed in. Blind (with a flat bottom if you want one), Up to next or Through all, with a flip, Start from sketch plane, and the parts to cut. The sizes come from the kernel's tables, each read from its standard (ISO 273 clearances, ISO 2306 tap drills, DIN 974-1 counterbores, DIN 74 countersinks). Pointing at a hole in the feature list shows what a drawing would say of it, such as `M6×1 tapped 12 deep, drill ⌀5 15 deep, 118° point`, so a tapped hole's thread is written there though it isn't modelled.
- **A volume the kernel can't measure closely** shows as `± error` in the status bar and Mass properties, with a warning mark, as where faces meet nearly tangent along an edge it can only trace.
- **Notes on features:** when the kernel notes something about a feature that built, such as a blind hole deeper than the part going right through, the row gets an ⓘ mark and pointing at it says what.
- **Thin, as in Onshape:** extrude, revolve, sweep and loft have a Thin section that makes a wall along the outlines instead of filling them: Inside, Outside or Both, at a thickness. With Thin on, an extrude or revolve can take a whole sketch of open curves, which has no regions to pick.
- **Rib, Split, Scale and Stretch, as in Onshape:** Rib makes a wall along a sketch's open lines until it meets the part, across the sketch plane as a gusset or out of it along the normal, with a flip and Extend profiles to part. Split cuts parts into pieces by a plane, along the whole surface of a face, or by another part. Transform can scale parts the same in every direction about a point, or along X, Y, Z or a picked line, and can rotate about a picked line. Helix can turn about a picked line too.
- **Variables:** any dimension takes an expression, like `width / 2`.
- **Configurations, as in Onshape:** the caret beside Variables saves their values under a name, and the Configuration list switches between the sets, as one change to undo. It says when the values have moved away from the configuration chosen, and offers to update it. They're kept in the document's `app` data.
- **Measure, as in Onshape:** select faces and edges and the corner of the view says what they measure: an area, a length, a diameter and radius, the distance between parallel faces or lines, the angle between them, the distance between two holes' centers or from an axis to a face, and totals for more.
- **Mass properties:** for the parts selected, or every part: volume, mass from a material you give them (it's kept with each part), the center of mass and the moments of inertia about it.
- **Section view and display, as in Onshape:** Section view, in the view menu or the toolbar, cuts the model with Top, Front, Right or a flat face (right-click it for Section view here), with a slider for where and a flip for which side stays. The cut looks filled in. The view menu also has Shaded, Shaded without edges, Shaded with hidden edges, Hidden edges removed, Translucent and Hidden edges visible.
- **Right-click in the view, as in Onshape:** a face or edge offers Edit for the feature that made it, a plane from a flat face, Section view here, Flange on sheet metal, the part's appearance and flat pattern, and hiding the part or every other part. The Parts list has Hide other parts and Show all parts too.
- **Toolbar, as in Onshape:** tool groups that don't fit the window go into a menu at the end of the row.
- **Tabs, as in Onshape:** Part Studios, Assemblies and folders along the bottom, with + to create them. A new document starts with one Part Studio and one Assembly. Each Part Studio is its own model, with its own undo, view and autosave. Drag a tab to reorder it, or onto a folder to move it in. Clicking a folder shows just its tabs. Right-click for rename, duplicate, delete, moving and unpacking. The icon beside + opens the tab manager, a searchable tree of everything.
- **Files:** autosave, `.coreshape` open and save, STEP import and export, STL export, and a sheet metal part's flat pattern as DXF. A `.coreshape` file holds one Part Studio and opens as a tab of its own; a `.schmishape` file holds the whole document.
- **STEP import, as Onshape's:** each solid comes in as a part of its own, named as it was in the file, with repeated names numbered. A card in the corner shows the file, a bar that follows the kernel through reading, building each solid and measuring the parts, the time, and Stop. When it's done it says how many parts came in and fits the view. A solid the kernel can't bring in is left out, and the card lists each one and why. When nothing can come in it says why in plain words, such as a damaged file or a file that isn't STEP, with what to try, and nothing is left in the history. A large file's text is kept apart from the document, by its hash, in IndexedDB, so undo and autosave stay small, and a saved `.coreshape` file has it all. Each distinct shape is meshed once and drawn at each of its copies. Opening a document with a long rebuild shows what the kernel is on in the status bar.
- **Versions, as in Onshape:** the clock beside Undo opens Versions. Create one with a name (V1, V2, … if left blank) and a description, and it keeps every tab as it is: Part Studios, assemblies and where dimensions sit. Restore puts the whole document back as it was, after keeping the document as it is now as a version, so restoring is never a loss. Each version can be saved to a file or deleted. Versions are kept in the browser's IndexedDB, and an import they hold is kept with them.
- **The whole document as a file:** Save the whole document (Ctrl Shift S) writes every tab, with imported files' texts, into one `.schmishape` file, and Open a document file (or Ctrl O) opens one in place of this document, keeping this one as a version first. That's the way to keep work anywhere other than this browser.
- **Keys:** `?` lists them all and `Ctrl K` searches every command. Right-click any plane or surface for New sketch. On a curved surface the sketch goes on the plane touching it under the cursor.
- **Mouse, as in Onshape:** right drag rotates, freely, around the point on the model under the cursor, or the model's center from empty space. Alt with right drag keeps Z upright. Middle drag or Ctrl with right drag pans, and scroll zooms. The left button selects: click, Shift to add, or drag a box.
- **Links to parts while sketching, as in Onshape:** with the select tool, a part's corners and edges can be hovered and selected where they can be seen. Coincident (or any constraint) between a sketch point and a part's corner or edge brings that corner or edge into the sketch as linked geometry, drawn in violet, and the point follows it when the part changes. Drawing onto a part's corner snaps to it and ties there too. Use (U) brings selected edges in as curves of the sketch, still following the part, as Onshape's Use does. Linked geometry is fixed: it can't be dragged.
- **Constraint tools, as in Onshape:** every constraint button can always be clicked. With what it needs already selected, it's added at once. Otherwise the button stays pressed and takes clicks, adding the constraint as soon as the picks fit and staying on for the next pair, until Esc or another tool. The status bar says what each one takes, and picks that can't fit say why.
- **Sketch mode** only changes the toolbar. The camera and planes stay as they were, and opening an existing sketch rolls the model back to that step. The left button draws, and right-click has Normal to sketch plane. Esc steps back through the drawing, the tool and the selection, then keeps the sketch and leaves.
- **Dimensions:** click something and the dimension appears with its current value, following the cursor. Where you pull it decides horizontal, vertical or aligned, and a second click on something measures between the two. Press, pull and release works too. Drag a placed dimension to move it, and double-click it to change it. Only sizes count: 90 on something at -90 keeps it where it is. Where labels sit is kept in the browser, not in the `.coreshape` file, whose reader refuses fields it doesn't know. The view cube's faces, edges and corners are all clickable, its arrows turn the view 15° or 90° with Shift, and dragging it rotates.

## How it fits together

```
Sidebar, sketcher, viewport ─┐
(next) built-in AI panel    ─┼─► CoreShape's MCP tool layer ─► kernel
(next) Claude Code bridge   ─┘   compiled to WebAssembly, in a Web Worker
```

The UI models only through the same tools an AI uses, so anything you can do, an AI can do too, and its
work lands in the same history. `window.schmishape.engine.call(tool, args)` is that API, from the console.

| Path | Contents |
|---|---|
| `engine/` | The Rust glue: the tool layer, plus what a screen needs and a tool shouldn't return as JSON, which is display meshes, with each body's faces and edges, STL bytes and parameter values. It meshes the kernel's own rebuild, so nothing is built twice |
| `src/engine/` | The worker and its client. Restores the document if the kernel crashes or is stopped |
| `src/store/doc.ts` | The document as the UI sees it: every change, undo, rollback and autosave |
| `src/drawing/` | Drawing tabs: the kernel's drawing JSON with where it's from, drawn by the engine's `sx_drawing`, which lays out a copy of a Part Studio's document, or an assembly's parts where they are, and writes SVG, PDF, DXF or PNG |
| `src/assembly/` | The mate solver (`solver.ts`, plain math, tested alone by `scripts/test-assembly-solver.mjs`), connectors, and a store. A second kernel worker reads each Part Studio's parts, so the main document isn't disturbed, and instances are baked into one mesh. This all lives in the app and isn't reachable through the tool layer yet. The kernel gained its own `coreshape-assembly` crate and tools while this was being built, and this doesn't use them |
| `src/store/tabs.ts` | The tabs and folders. The kernel holds one document at a time, so switching tabs puts one away and opens the other |
| `src/features/` | Each feature's fields and JSON, and the dialog with its live preview |
| `src/sketch/` | The sketch session, its tools and snapping, the overlay that draws it, and each sketch's regions |
| `src/viewport/` | Camera and the hand-written WebGL2 renderer, with GPU picking |
| `src/ui/DialogFrame.tsx` | The movable, resizable window around every dialog |
| `src/ui/` | The interface. `src/commands.ts` is the list behind the toolbar, palette and shortcuts |

## Design

A dense, serious tool: icon-only toolbars with fast tooltips, a text menu bar, and Inter at 12px. Icons are drawn
like technical drawings, with one-pixel lines and what the tool acts on in amber. Light grey chrome around a
near-white viewport, with faint planes and a clear part view as in Onshape. Amber is the one highlight colour.

## Workarounds to remove

These exist so that `core_shape` stays untouched. Each one wants a small change there.

- **A revolve's axis is kept as numbers.** The kernel takes an axis as a point and a direction, so a revolve about a sketch line remembers which line in its `app` data, and the app rewrites the axis whenever that line moves. An axis that names the line would follow it by itself, for an AI too.

Older documents made hidden copies of sketches, named `~axis:<id>` for a revolve and `~regions:<id> <n>` for an extrude of some regions, from before the kernel's revolve took an axis and its extrude took regions. Opening one turns them into plain features, with the same shape and face names.

## Known gaps

- **Sketches on a face don't follow it.** The plane is copied when the sketch starts, so moving that face later doesn't move the sketch.
- **No AI panel yet,** and no bridge for Claude Code, though the tool API it would use is in place.
- **Not built yet in assemblies:** placing by clicking in the view, subassemblies, groups, offsets, limits, relations, explicit mate connectors, Snap mode, and exporting or saving an assembly to a file. An exploded view's steps only shift, not turn, though the kernel's can. A named position keeps where the parts are rather than the mates' values, as the app's mates have none.
- **Drawings are placed by the kernel, not by hand:** views can't be dragged, and a dimension is picked from a list of sketch points or typed rather than clicked on the sheet, since the app doesn't know where the kernel put each view. A section that misses the part fails the whole drawing, saying which. A dimension on an assembly drawing takes typed places only, as the kernel's does.
- **Not built yet:** Transform between two places (`frames`) and fillets with several sets of radii have no dialog.
- **Part colors and names are for Part Studios.** Assemblies still show every part in grey, under its default name.
- **Sheet metal is stage 1 of the kernel's:** sheet metal model, flange and the flat pattern. Bend, hem, joints, corner and bend reliefs, and converting a part are waiting on the kernel, and so is lighting a bend on the folded part from its table row. A tab is an extrude kept with the sheet's thickness, so it doesn't follow a thickness typed in later, only one given by a variable.
- **Mass properties come from the mesh,** scaled to the kernel's exact volume, so the center of mass and inertia are as close as the mesh is to the part.
- **Plain `sketch` features,** which only an AI or a file can make, show in the history but can't be edited or drawn in the view.
- **A large STEP import is slow, and so is reopening it.** A 114 MB assembly of 711 solids (2,218 parts) takes 2½ to 3½ minutes, more than half of it the kernel measuring every part for its summary, and the same again each time the page opens it, as the kernel translates the file again. It peaks at about 3.4 GB of the browser's 4 GB for WebAssembly, so a much bigger file will run out of memory, which the card says.
- **Checked in Chrome only,** with software rendering and on an NVIDIA RTX 3060. It hasn't run in Firefox or Safari, or been installed as an app.
